# Weak Factor Analysis via Temporally Weighted PCA

Code and data for reproducing the simulation and empirical results in *Weak Factor Analysis via Temporally Weighted PCA*.

## Requirements

The scripts require R, `MASS`, and `ggplot2`. Run all commands from the repository root.

## Reproducing the results

Run all figures and tables with the settings used in the paper:

```bash
Rscript scripts/run_all_paper_outputs.R
```

For a shorter test run:

```bash
Rscript scripts/run_all_paper_outputs.R quick
```

Quick mode uses fewer Monte Carlo replications and writes to the same output directory. Run the default command again to regenerate the results with the full simulation settings.

Generated figures are written to `outputs/figs/`; tables and supporting CSV files are written to `outputs/tables/`.

## Files

- `scripts/`: scripts for individual figures and tables
- `R/`: estimation, simulation, and data-processing functions
- `data/`: February 2025 vintages of FRED-MD and FRED-QD
- `data/cache/`: checksummed table-level caches used by `Table4.R` and `Table5.R`
- `diagnostics/`: normalization check for the inference results
- `outputs/`: generated figures and tables

## Running one script

Examples:

```bash
Rscript scripts/Figure2.R 300 20260315
Rscript scripts/Table2.R 100 1234
Rscript scripts/Table3.R 100 1234
Rscript scripts/Table4.R cached
```

The optional arguments are:

- `Figure1.R` through `Figure6.R`: `[n_rep] [seed]`
- `Figure7.R`: `[seed]`
- `Table2.R` and `Table3.R`: `[n_rep] [seed]`
- `Table4.R` and `Table5.R`: `[recompute|cached] [n_rep] [seed]`

For the last group, `n_rep` and `seed` are used only in `recompute` mode.
The `cached` mode accepts only the table-level CSV named in
`data/cache/table_cache_manifest.csv`. It verifies the manifest identifier,
schema, row count, and MD5 checksum before use. No other cache format is read.
If a verified cache is absent or fails validation, use `recompute` with the
paper settings shown below.

## Paper settings

| Outputs | Replications | Seed |
|---|---:|---:|
| Figures 1, 4, and 5 | 500 | 123 |
| Figure 2 | 300 | 20260315 |
| Figures 6 and 7 | 500 | 1234 |
| Figure 3 | randomized CV with \(J=10\) over 10 expanding windows | 20260315 |
| Tables 2--5 | 100 | 1234 |

For Figure 3, the expanding windows advance by 24 observations for FRED-MD and 8 observations for FRED-QD. The minimum allowed training sizes are 240 and 80 observations, respectively.

All numerical AdaWPCA cross-validation calls use retention probability
`p_star = 0.8`, ten equally spaced candidates on `[0, 1]`, and `J = 10`
random splits. Each candidate is scored by the mean of the validation-set MSEs.

## Implementation details

- Symmetric WPCA uses eigenvectors associated with the largest algebraic eigenvalues.
- The numerical experiments specialize the general Toeplitz-weight formulation
  to maximum lag `K0 = 1`; rank-one simulation and inference paths use explicit
  two-dimensional matrix representations throughout.
- The simulation factor transition is \(0.9I_r\), and the loading matrix is \(1.2U_sD_L\).
- Subspace errors are raw Frobenius norms of the difference between projection matrices.
- The inference simulations use right alignment and rotation-compatible whitening.
- In the FRED reconstruction experiment, AdaWPCA's inner CV splits only entries
  retained by the outer training mask; outer test entries are excluded from both
  inner fitting and inner validation. Inner reconstructions use the product of
  the outer and inner retention probabilities for inverse-probability scaling.
- FRED series with at most 5% missing observations are retained before
  complete-case balancing.
- `scripts/Table5.R` also records the reproducible eigenvalue-ratio diagnostic
  with `R = floor(N / 2)` in `Table5_fred_rank_diagnostic.csv`. This supporting
  CSV does not replace or alter the paper's Table 2 reconstruction results.

## Diagnostic

Run the normalization diagnostic:

```bash
Rscript diagnostics/check_inference_normalization.R
```

It checks the whitening identities and summarizes the normalized loading and factor statistics. An optional first argument sets the number of replications.

See [REPRODUCIBILITY_CHECKS.md](REPRODUCIBILITY_CHECKS.md) for checksums and numerical checks.
